UnrealPSKPSKA
A PSK importer for Unreal Engine 5.3.2 (PSKA does not work so use UEFormat plugin and .ueanim for this.
*This plugin imports vertex colours correctly in UE 5.3.2, whereas .uemodel does not. Ideal combo = .pskx + .ueanim for most complete data*

🔧 Installation & Usage
Download
Create a "Plugins" folder in your Unreal project
Copy the "UnrealPSKPSKA" folder and paste it in the "Plugins" folder
If your project cant be compiled automatically (message), rebuild it in visual studio
